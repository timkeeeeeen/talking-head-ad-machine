# Ad Test Lab

Start from one approved core ad.

1. Record the test hypothesis and the one variable intended to change.
2. Prefer three hook variants sharing one body before changing body, CTA, graphics, or format.
3. Keep source ranges, claims, captions, and proof traceable to the approved job.
4. Name variants deterministically from campaign, variable, value, ratio, and revision.
5. Render a low-resolution batch first.
6. Build a side-by-side comparison with duration, changed variable, QA, and approval status.
7. Never call a visual difference a performance winner without ad-platform results.
