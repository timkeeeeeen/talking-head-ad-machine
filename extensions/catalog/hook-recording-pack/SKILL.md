# Hook and Recording Pack

Improve the next recording without inventing evidence or promising performance.

1. Read the offer, audience, desired action, available proof, and prohibited claims.
2. Create three meaningfully different hook directions before multiplying scripts.
3. Keep one shared body when the buyer intends to test hooks.
4. Write for natural speech, complete thoughts, clean edit handles, and one CTA.
5. Ask for alternate hook and CTA takes with two seconds of silence before and after each take.
6. Produce a proof-shot list using only product screens, demonstrations, or evidence the buyer can supply.
7. Run the recording checklist before the buyer records.

Do not describe this module as required for editing an existing video.
