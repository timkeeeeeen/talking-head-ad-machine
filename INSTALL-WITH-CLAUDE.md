# Install with Claude Code

1. Unzip the product into a normal writable folder.
2. Open that folder in Claude Code.
3. Say: `Install this product, check my computer, repair ordinary setup problems, and render the included demo.`
4. Let Claude inspect the installation plan and run `install.sh` on macOS or `install.ps1` on Windows.
5. Approve a password or administrator prompt only when your operating system presents one.
6. Do not begin a real ad until doctor passes every required check and the included demo renders successfully.

If setup cannot be repaired, say: `Create a sanitized support report and explain the exact failed check.`
