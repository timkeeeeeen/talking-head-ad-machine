# Privacy

Transcription, cutting, compositing, and rendering use local tools by default. The product does not publish ads or intentionally upload footage.

Codex or Claude may receive prompts, transcripts, inspected frames, file metadata, and other task context under the selected provider's terms. Do not describe the overall workflow as fully offline.

Cloud transcription, rendering, generated media, or publishing requires explicit approval before media or data leaves the machine.

Sanitized support reports omit footage, transcripts, credentials, and source paths by default. Review the archive before sending it.
