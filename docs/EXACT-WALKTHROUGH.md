# Exact first-ad walkthrough

1. Unzip the product into a normal writable folder.
2. Open the unzipped folder in Codex or Claude Code. On macOS, you may also use the included `.command` launcher.
3. Say: `Install this product, check my computer, repair ordinary setup problems, and render the included demo.`
4. Let the agent run `install.sh` on macOS or `install.ps1` on Windows. Approve a password or administrator prompt only when the operating system presents one.
5. Wait for doctor to report every required check ready and for the included demo to render. Installation messages alone do not prove readiness.
6. Say: `Turn this video into a 4:5 Facebook ad: [drag video here]. Preserve my meaning, do not invent claims, and open a preview before finalizing it.`
7. Tell the agent the offer, audience, desired action, allowed evidence, and claims to avoid.
8. Let the agent preflight the footage. Rerecord if the footage cannot support a credible ad.
9. The agent conforms captions to the edited timeline, prepares the selected social ratio, adds a source-backed hook and your desired action, and checks sampled frames before rendering.
10. Review the source and edited preview, cut plan, low-confidence decisions, captions, graphics, and QA report.
11. Ask for one specific revision at a time or explicitly approve the preview.
12. Keep the MP4, captions, edit plan, and receipts together. Request the optional Resolve handoff only if useful.

The agent never publishes the output.
