# Exact first-ad walkthrough

1. Unzip the product into a normal writable folder.
2. Double-click the launcher for Codex or Claude Code.
3. Say: `Set this up and run the included demo.`
4. Wait for the doctor to report all required checks ready and for the local demo review page to open.
5. Say: `Turn this video into a 4:5 Facebook ad: [drag video here]. Preserve my meaning, do not invent claims, and open a preview before finalizing it.`
6. Tell the agent the offer, audience, desired action, allowed evidence, and claims to avoid.
7. Let the agent preflight the footage. Rerecord if the footage cannot support a credible ad.
8. The agent conforms captions to the edited timeline, prepares the selected social ratio, adds a source-backed hook and your desired action, and checks sampled frames before rendering.
9. Review the source and edited preview, cut plan, low-confidence decisions, captions, graphics, and QA report.
10. Ask for one specific revision at a time or explicitly approve the preview.
11. Keep the MP4, captions, edit plan, and receipts together. Request the optional Resolve handoff only if useful.

The agent never publishes the output.
