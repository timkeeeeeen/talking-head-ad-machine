# DaVinci Resolve handoff

The reliable handoff is a flattened high-quality master, output-timed SRT, normalized edit plan, receipts, and available audio stems. Resolve can import these without reconstructing the automated composition.

FCPXML is a best-effort bonus for a simple single-source, constant-speed, straight-cut timeline. It does not represent effects, captions, reframes, transitions, retiming, external audio, or nonzero camera timecode.

If FCPXML import or relinking is not immediately straightforward, use the flattened master rather than turning Resolve reconstruction into part of the core workflow.
