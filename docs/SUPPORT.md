# Support boundary

Support for the initial product covers setup, the product-specific doctor, and the included deterministic demo on configurations listed as supported at purchase.

Support does not include custom editing, creative consulting, operating-system repair, bespoke code, ad-platform publishing, unsupported computers, or indefinite compatibility with future dependency releases.

Recommended guarantee for the funnel: if the included demo will not render on a computer and operating system explicitly listed as supported at purchase, the buyer may send the generated doctor report within 14 days and request a refund.

Do not promise lifetime updates. Define the version-one bug-fix policy before public launch.
